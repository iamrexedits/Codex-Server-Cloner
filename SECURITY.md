## Security Policy for Codex Server Cloner

### Supported Versions
We currently support the latest version of the project. Older versions may not receive security updates.

### Reporting a Vulnerability
If you discover a security vulnerability in Codex Server Cloner, please report it responsibly. Do not open a public issue on GitHub for security-related matters.

- **Email Us**: Send details to [iamrexeditsofficial@gmail.com](mailto:iamrexeditsofficial@gmail.com).
- **What to Include**:
  - A clear description of the vulnerability.
  - Steps to reproduce it.
  - Potential impact.
  - Any suggested fixes.
- **Response Time**: We aim to acknowledge your report within 48 hours and provide a fix timeline if applicable.
- **Disclosure**: We practice coordinated disclosure. Once fixed, we'll credit you (if desired) in the release notes.

### Best Practices for Users
- Never share your Discord bot tokens or API keys.
- Use the tool only on servers where you have admin permissions.
- Regularly update to the latest version for security patches.
