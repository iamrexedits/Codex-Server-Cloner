## Contributing to Codex Server Cloner

Thank you for your interest in contributing to Codex Server Cloner! This is an open-source project aimed at allowing users to clone Discord server structures and configurations to their own servers. We welcome contributions from everyone to help improve and expand the project.

### Code of Conduct
Please note that this project adheres to a [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/0/code_of_conduct.html). By participating, you are expected to uphold this code. Report unacceptable behavior to the project maintainer at [iamrexeditsofficial@gmail.com](mailto:iamrexeditsofficial@gmail.com).

### How to Contribute
1. **Fork the Repository**: Start by forking the repository at [Codex-Server-Cloner](https://github.com/iamrexedits/Codex-Server-Cloner).
2. **Clone Your Fork**: Clone your forked repository to your local machine.
3. **Set Up Your Environment**:
   - Ensure you have Node.js 20 or higher installed.
   - Install dependencies: Run `npm install` 
   - Obtain a Discord account token and configure it in a `.env` file (never commit secrets!).
4. **Make Changes**: Create a new branch for your feature or bug fix (e.g., `git checkout -b feature/new-clone-option`).
5. **Test Your Changes**: Run local tests to ensure everything works, including cloning a test server.
6. **Commit Your Changes**: Use clear commit messages (e.g., "Add support for cloning roles").
7. **Push to Your Fork**: Push your branch to your forked repository.
8. **Submit a Pull Request**: Open a PR against the main repository at [Codex-Server-Cloner](https://github.com/iamrexedits/Codex-Server-Cloner). Provide a detailed description of your changes, including any relevant issues it addresses.

### Reporting Issues
- Use the GitHub Issues tab at [Codex-Server-Cloner/issues](https://github.com/iamrexedits/Codex-Server-Cloner/issues) to report bugs, suggest features, or ask questions.
- Check for existing issues before creating a new one.
- Provide as much detail as possible: steps to reproduce, expected vs. actual behavior, screenshots if applicable.

### Style Guidelines
- Oraginzation and expansion of code files of project is allowed 
- Write clear, commented code.
- Ensure your code is compatible with Discord's API.

### Legal Note
This tool is intended for educational and personal use on servers where you have appropriate permissions.
